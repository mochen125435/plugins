# magpie-custom-plugins

Two providers for [magpie](https://usemagpie.ai):

- **麦块云 (minekuai)** — `index.mjs` exports `MinekuaiPlugin`
- **超算互联网 (SCNet)** — `index.mjs` exports `ScnetPlugin`

Install from this branch and sign in to each provider separately.

```sh
magpie plugin add "github:<owner>/plugins#custom"
```
